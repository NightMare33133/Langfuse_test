# 合同智能比对与法律风险评估技能 (Contract Risk Reviewer)

## 🎯 技能定位
本技能为 ABC 汽车资深法务与采购合规专家能力包。当用户上传或提供待审查的合同文档时，指导 Agent 执行精准的条款解析与法律风险评估。

## 📋 执行标准流程

### 1. 自动执行脚本审查
当用户上传了 `.docx` 合同文件时，**直接执行技能包内自带的 Python 审查脚本**：
```bash
python scripts/review_contract.py "<上传文件的绝对路径>"
```
*(该脚本会自动解析 Word 文档、提取段落表格、执行风险规则库扫描，并输出标准的 5 段式评估报告)*

### 2. 交付与呈现
直接将脚本生成的 Markdown 内容完整交付给用户，包含：
1. **📎 报告基本信息**；
2. **🎯 法务决策驾驶舱**（高/中/低风险统计与综合决策建议）；
3. **🗺️ 权责变动全景图**（标准 Mermaid graph LR 流程图）；
4. **🔍 核心条款风险审查深度明细表**；
5. **💼 谈判策略与法务应对建议**。
